## 2. 页面与设计规范

- `public/index.html` 成为 P00，不再显示单一公司上下文或十页卡片墙；无项目时不显示项目实体操作条、模型动作或场景重置。
- 列表提供进行中、归档、全部，支持公司、年度、阶段和关键字筛选，以及更新时间/年度排序；无匹配时有恢复入口。
- 新建演示报告；重复组合提示已有项目，不能覆盖名称或清空进度。原型仅支持年度 HKEX 演示框架，最多 40 个本地项目。
- 全部十页保留业务布局。新增返回列表和切换项目；窄桌面可从面包屑里的公司下拉切换，不依赖会隐藏的侧栏项目卡。
- 原有 `--esg-*` token、深蓝侧栏、米白工作底色、绿色主操作、表格、标签和对话框不变。P00 使用同一组 UI 构件与 SVG 图标，没有引入第二套视觉库。
- 后续工程候选对应：AntD Table、Tabs、Select、Input.Search、Modal/Form、Tag、Progress、Dropdown；仅为组件承接记录，不表示已经改为 React/AntD 实现。

## 3. 状态与数据契约

| 对象 | 保存位置 / 规则 |
| --- | --- |
| 项目目录 | `openesg-projects:v1`；未保存时使用四个预置项目，其中一个归档 |
| 原始项目 PRJ-DEMO-001 | 保持原键 `openesg-demo:v1`，不迁移或自动重置已有业务操作 |
| 其他项目 | `openesg-demo:v1:<projectId>`；各自基线、overrides、runId、revision、筛选、快照与任务 |
| 跨页链接 | `#project=…`，对象/Mapping/定位/快照参数仍保留；无 project 的旧业务链接默认打开原始项目 |
| 切换项目 | 打开另一个已保存工作区，不重置任何项目；未保存正文和本页提示词草案不随切换保留 |
| 切换场景 / 重置 | 仅重置当前项目，保留其身份和报告期，不触碰其他项目目录或状态 |
| 归档 / 恢复 | 仅修改目录归档标志；业务对象、正文、构建版本不变。归档阻止业务写操作、模型推进和场景重置，恢复不等于重新创建 |
| 快照 | 仍为只读版本；只可导入所属项目，跨项目快照被拒绝；预置项目快照仍可配合 JSON 跨浏览器分享 |

每个项目使用同一套虚构场景模板，但对象图、路径、报告期、正文公司名和冻结报告各自生成。重新计算内容指纹，不将旧内容的批准指纹冒充新内容批准。`assets/demo-files` 保留共享的原始演示附件模板；页面中的项目预览由各项目对象图生成，并非真实客户文件解析。

P00 单元进度及待审核/复核对象数复用 `ESG.stats()`，与 P01 相同。阶段从覆盖、来源、事实、单元、预检与最新构建状态派生；有待审核的项目数与对象数分别显示。归档不是审核通过，构建批准也不代表所有新增上游事项已处理。

限制：目录和项目状态均为设备本地，不是多人协同、账户服务或生产项目管理。新建的自定义项目不会因发送网址而出现在同事浏览器中；本轮不提供项目目录导入。P02/P07 提示词仍是上一轮约定的本页设计草案，未借本轮扩展实现提示词发布服务或跨页持久同步。

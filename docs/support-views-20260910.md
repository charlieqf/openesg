日期：2026-09-10。范围：用户批准的“4 个支撑视图 + 现有页面状态补充”。目标代码为本仓库 `public/`；未修改生产系统、读取客户资料包或开发真实后台。

交付状态：本地实现；发布情况见 [Cloudflare 部署记录](cloudflare-deployment.md)。不得把本轮本地验收当成线上验收。

## 1. 页面组织与设计沿用

P00 是跨报告项目入口，P01–P10 仍为报告工作流。P11–P14 归入独立“项目支撑”导航组，不改动十步工作流的顺序。访问支撑页时，侧栏滚动到当前入口；窄窗口继续使用现有紧凑侧栏。

| 页面 | 主要内容 | 与工作流的联系 |
| --- | --- | --- |
| P11 项目配置与运行环境 | 项目范围、市场/行业/语言、目录与模拟模型服务、六类角色、配置 Diff、无权发布状态 | P01 项目配置入口；离线时可返回 P08 人工处理 |
| P12 合规来源与采用版本 | 主规则、FAQ、附件；日期/URL/指纹/规范化状态；旧版回看、失败重试、候选输入 | P02 双向入口；采用候选来源不等于发布清单 |
| P13 行业参考与模板库 | 报告/行业/年度/语言筛选、来源定位、章节/表格/图注样例；正式框架继承分区 | 参考关联到 P07/P08 的指定要点；空白项目可采用模板生成空白要点 |
| P14 运行记录与影响分析 | 依赖范围、节点详情、恢复与审核等待；共享模型任务、完整审核与操作事件 | 链接实际事实/映射/单元/冻结报告；任务详情仍使用共享模型动作中心 |

按网站构建技能的复用与一致性要求，保留静态 HTML、共享 UI 函数及 `--esg-*` token；没有迁移框架、引入新组件库或改变托管平台。新增 `support.css` 只扩展现有深蓝、绿色、浅底色、表格、面板与对话框模式。工程承接时可继续映射既有 AntD Table、Tabs、Form/Select、Modal/Drawer、Tag、Alert；本轮没有安装 AntD。

## 3. 关键演示约定

### 3.1 空白与沿用配置

- P00 默认“全新空白报告”；可以选择“沿用已有报告配置”或“载入完整虚构演示样例”。已有报告仍直接从列表进入。
- 沿用只复制范围、行业、语言等配置，不复制事实、资料、正文、审核记录或历史构建。新项目保留自己的 ID、年度和路径。
- 空白项目采用来源后出现待审条目；采用模板后出现未开始的空白单元，没有已批准评论、审核指纹或虚构历史成品。
- 首次导入文件展示登记/解析/失败/归组的状态设计，不接入真实文件选择或解析服务。需要演示完整证据链时，明确选择现有完整演示场景，不把空白项目悄悄填成客户资料。

### 3.2 提示词配置的两种演示边界

手工提示词草案仍留在本页内存；本轮没有把用户输入接入真实发布引擎。新增的是命名状态样例：已发布 v1、v2 待审核、v2 被退回、v2 已发布并选择采用版本、相关要点采用 v2。

样例针对 CHK-ENV-001。受影响要点从 `checkIds` 派生，不写死数量；v2 补充边界与上年可比性的写作/逐项检验要求。P07 的继承预览、P08 的组合预览及模型弹窗采用同一要点配置身份。未选择升级仍用 v1；不相关要点不升级。

“v2”表示下一版清单提示词配置的设计快照，页面明确指出它不发布下方业务对象图中的清单。新模型动作保存所用样例配置身份；旧任务、旧正文与冻结报告不被重写。不是一个脱离清单版本管理的生产提示词服务。

切换命名状态会重置本组采用选择和本页提示词草案，不重置资料/事实/正文。全局“重置演示”才会恢复当前项目的整个基线。不同项目之间不共享这些状态。

### 3.3 对象、角色与运行记录

- 新视图同样提供路径、打开文件、复制路径、受限上下文、Diff；支撑页另有可复制版本深链接与配套快照。路径为示意，不连接用户磁盘。
- 六类角色按需求 §16.1：合规管理员何宁、收资管理员许岚、事实审核人陈澄、ESG 撰写人林悦、报告审核人周宁、系统管理员沈言，全部为虚构身份。前五项与原型已有审核身份一致。G5 与 G6 是两次独立审核，不是新增一个与需求不一致的角色。
- 变更影响页把假设事件和实际关系分开：事件是命名样例，受影响事实版本、映射、单元和不受影响对象从当前图派生。模型任务页签直接读取 `g.actions`，不造第二套模型任务；审核页签读取 `g.audit`。
- “从失败节点继续”仅演示失败→恢复→停在审核门，不运行 DAG、不自动批准、不修改正文。当前样例对应环境事实的依赖路径；不是任意 DAG 运行服务。

### 3.4 参考、样式与导出

- 参考报告、日期、URL 和规则条文全部虚构；`.example` 地址是占位地址。不会提取真实客户附件中的正文或数值。
- 参考绑定只写设计关系，不生成 FactVersion，不改变映射和覆盖率。正式框架与参考写法分区管理。
- P09 样式检查器有标题层级、图注位置、分页的即时预览，但不修改真实正文或生成分页文档。
- P10 的待生成/生成中/失败/已生成是视觉状态。DOCX/PDF/XLSX 未产生二进制文件，没有伪装下载。新增覆盖 JSON 示例从选中构建的冻结内容生成，明确与现有 CSV、未来 XLSX 区别。

## 4. 文件与验证入口

- 4 个新 HTML：`public/11-project-settings.html` 至 `public/14-runs-and-impact.html`。
- `public/assets/support-data.js`：虚构目录、命名状态、派生关系、设计动作与空白初始化；`support.js`：视图与交互；`support.css`：沿用原 token 的布局扩展。
- `shared.js`：统一存储、只读/过期保护、支撑路由、模型样例配置快照；`projects-data.js`：创建方式与配置继承；现有页面引用相同资源。
- `npm run build`：原状态、项目、支撑状态、公开资源与 HTTP 边界检查。
- `npm run test:support`：新页、状态、深链接、空白流程、参考及格式状态检查；默认预览端口 4174。
- `npm run test:design`、`test:portfolio`、`test:flow`：原十页设计、项目隔离及完整证据到报告链路回归。
- 浏览器检查使用本机已安装的 Playwright，通过 `PLAYWRIGHT_PATH` 指定；未新增应用依赖。
